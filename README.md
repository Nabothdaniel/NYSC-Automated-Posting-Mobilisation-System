# NAPS — NYSC Automated Posting System

**A Multi-Criteria Decision Support & Mobilisation Platform for the National Youth Service Corps (NYSC)**

The full Next.js 15 + TypeScript + Firebase application is located in the [`./naps`](./naps) directory.

---

## Quick Start

```bash
cd naps
npm install
npm run seed
npm run dev
```

See [`naps/README.md`](./naps/README.md) for full architecture, role credentials, unit tests, and Vercel + Firebase hosting instructions.
